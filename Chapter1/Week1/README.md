## Clickable Image
You can double-click the PictureBox control in the Designer to create a Click event handler, then add your code to it.

## Label Control
Text: Displays text on the Label.
Example: Text = "Student Name"
To clear a Label's text, simply assign an empty string ("") to the Text property.

## MessageBox
Show(): Displays a message to the user.
Example: MessageBox.Show("Hello");

## Close
Close(): Closes the current form or window.
Example: this.Close();
